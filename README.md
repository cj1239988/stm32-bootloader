# STM32 Bootloader

## 项目简介

本项目基于 STM32F407 实现一个串口 Bootloader，用于学习和实现 MCU 在线升级（IAP）流程。

目前按照模块逐步开发，每完成一个功能都会进行一次 Git 提交，并记录开发过程。

## 通信协议

### 数据包格式

| 字段 | 长度 |
|------|------|
| Header | 1 Byte |
| Opcode | 1 Byte |
| Length | 2 Bytes |
| Payload | n Bytes |
| CRC16 | 2 Bytes |

支持的命令：

- ERASE（擦除 Flash）
- PROGRAM（写 Flash）
- VERIFY（CRC 校验）
- BOOT（跳转 APP）

## 功能说明

### UART 异步接收

串口接收采用环形缓冲区进行异步处理。

USART 接收中断中只负责快速读取数据并写入 ring buffer，主循环再从 ring buffer 中逐字节取出数据并交给状态机解析。

这样可以避免在中断中进行复杂解析或 `printf` 打印日志导致串口后续数据丢失。

### 接收超时检查

Bootloader 在接收数据包过程中增加了超时检查。

如果长时间没有接收到新的字节，状态机会认为当前数据包接收异常，并重置解析状态，避免半包数据一直卡在接收流程中。

### CRC16 校验

数据包末尾增加 CRC16 校验字段。

Bootloader 在接收到完整数据包后，会根据数据内容计算 CRC16，并与数据包中的 CRC16 字段进行比较。

如果 CRC 校验失败，说明数据包在传输过程中可能发生错误，Bootloader 会拒绝处理该数据包。
